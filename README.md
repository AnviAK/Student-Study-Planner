\#	Project

Student Study Planner



\##	Description

A Java-based study planner that helps students to manage assignments, track it's completion status, and save assignments for future use.



\##	Features

* Add assignments with a name, the course it aligns with, and the due date
* View all assignments
* Mark completed assignments
* Delete assignments
* Validate user input using exception handling
* Save assignments to a file
* Load saved assignments when program starts



\##	Technologies

* Java
* Eclipse
* Git
* GitHub



\##	What I Learnt

This project has helped me practice object-oriented programming, ArrayLists, exception handling, loops, conditions, and file I/O. Alongside, I also learnt how to use Git and GitHub to track and publish a project.



\##	How to Run

1. Clone/Download the repository.
2. Open the project in Eclipse.
3. Run 'Main.java'.
4. Follow the menu instructions in the console.
